# clinical-vlm-conflict-detection
Research on conflict-aware reasoning in medical vision-language models using EHR and chest X-ray data.
## Owner 5 - Conflict Detection

Implemented Defer Gate logic for identifying disagreements between image-only and image+lab predictions.

Results:
- Raw Accuracy: 24.3%
- Defer Accuracy: 24.7%
- Conflict Rate: 74.7%

## Owner 6 - Evaluation

Evaluated:
- Accuracy
- Conflict Rate
- Defer Gate Performance

Conclusion:
The Defer Gate approach showed a small improvement in accuracy while identifying conflicting predictions.
